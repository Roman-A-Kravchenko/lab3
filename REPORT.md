# Отчёт по лабораторной работе №3: линейные модели

## 1. Данные и подготовка

### Student_Performance.csv (линейная регрессия)

- Целевая переменная: `Performance Index`
- Признаки: `Hours Studied`, `Previous Scores`, `Extracurricular Activities`, `Sleep Hours`, `Sample Question Papers Practiced`
- Предобработка:
  - `Extracurricular Activities`: Yes → 1, No → 0
  - Масштабирование признаков и target выполняется **внутри** `train_linear_regression` (стандартизация по train)
  - Разбиение: `train_test_split(test_size=0.2, random_state=42)`

### german.csv (логистическая регрессия)

- Целевая переменная: `Creditability` (первый столбец)
- Разделитель: `;`
- 20 числовых признаков
- Масштабирование признаков выполняется **внутри** `train_logistic_classifier`
- Разбиение: `train_test_split(test_size=0.2, random_state=42)` (без stratify, как в исходном решении)

## 2. Гипотезы и эксперименты

**Гипотезы:**
1. Собственная реализация batch GD с `lr=0.1` и `epochs=1000` даст монотонно убывающую историю loss и метрики, близкие к sklearn.
2. Линейные модели будут лучше DecisionTree и KNN, потому что зависимость в данных преимущественно линейная.

**Параметры обучения:**
- Линейная регрессия: `learning_rate=0.1`, `epochs=1000`, loss = MSE
- Логистическая регрессия: `learning_rate=0.1`, `epochs=1000`, loss = Binary Cross-Entropy
- Сигмоида: `np.clip(z, -500, 500)`
- В BCE добавлен `eps=1e-15` для защиты от `log(0)`

**Особенности реализации:**
- Модели сами стандартизируют данные → их можно вызывать на «сырых» признаках.
- Веса и bias возвращаются в **исходном** пространстве признаков (удобно для интерпретации).
- MSE считается в исходных единицах target.

## 4. Выводы

1. **Корректность реализации.**  
   Собственная логистическая регрессия практически совпадает со sklearn (`ROC-AUC` одинаковый до 4 знака, разница F1 ≈ 0.003). Формулы градиентов и цикл обучения реализованы правильно.

2. **Сравнение с baseline:**
   - Собственная модель показывает лучший ROC-AUC и F1.
   - DecisionTree проигрывает по ROC-AUC и Recall (дерево без ограничения глубины на небольшом датасете легко переобучается / даёт менее калиброванные вероятности).
   - KNN занимает промежуточное место, но уступает линейным моделям — локальная структура данных выражена слабее глобальной линейной зависимости.

3. **Роль масштабирования.**  
   Без стандартизации градиентный спуск на этих данных нестабилен. После масштабирования сходимость быстрая и устойчивая.

4. **Высокий Recall (0.891).**  
   Объясняется дисбалансом классов (~70 % положительных) и порогом 0.5 — модель чаще предсказывает «кредитоспособен».
